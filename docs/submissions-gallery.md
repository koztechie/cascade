## Що це означає для Cascade (аналіз знімка21.11)

- **Забиті коридори:** пам'ять/уроки агентів (~10 робіт: ContextMesh, ToldOnce, WorkGraph, memory-pr, BEZEN, Xiaoyuan, LocalGraph Core, Thread Compass, Hive, Witness); код/git/зміни (~8: Ripple, DuolaWork, CodeContext, Precedent, TraceGraph, TraceWeaver, Data Impact Graph, DeltaX); evidence/lineage (~7); мед/наука (~6); безпека/інциденти (~5).
- **E-commerce / операції каталогу: жодної роботи.** Найближчий сусід — Warung Terhubung (склад ресторану). **Ніша Cascade у галереї вільна.**
- **«Change-impact» є, але не в нашому домені:** Data Impact Graph (data lineage у code review) і DuolaWork (agent work) — підтверджують, що ідея «що зламається» зрозуміла суддям, але в e-commerce її ще ніхто не зробив.
- **Path-as-proof — норма, а не фішка:** десятки робіт обіцяють «path as proof». Дистанція мусить бути у **виконанні** (робочий кінець, verify, вьюер, агент), а не в обіцянці.
- **Практичний висновок:** судитимуть ~55+ робіт; топ-3 забирає той, у кого найменший розрив між обіцянкою і тим, що запускається з першого разу. Наш `make verify` + вьюер + живий агент — саме про цей розрив.
